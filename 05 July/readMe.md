### OOPS [Object Oriented Programming] :-

Paradigm(way or style) of programming(writing code) that entire program revolves around objects.

### Objects :- real life data type.

- instance of class.

- methods[function defined inside the class] -> behaviour
- properties -> variable

### Class :- blueprint of object

- customize data type

### built-in methods of class:-

- [__init__] -> initializes the objects properties
- [__str__] -> changes what will be printed when you print an object

### 4 pillars of oops :-

1.  Encapsulation -> getter(value ko fetch krne k liye),setter(use value ko set/update)
2.  Abstraction -> [data hiding]
3.  Polymorphism -> poly(multiple) + morph(forms) => multiple forms of the same thing
    A. Compile Time Polymorphism(NOT APPLICABLE)
    b. Runtime Polymorphism
4.  Inheritance : inheriting the property of parent class to the children class
